# 🕷 S.P.I.D.E.R  
### Smart Predictive & Integrated Defect Evaluation Robot

S.P.I.D.E.R는 스마트팩토리 환경에서 발생하는 **설비 센서 데이터와 이미지 데이터를 통합 분석**하여  
설비 이상을 사전에 감지하고, 제품 불량을 실시간으로 검출하는  
**AI 기반 통합 예지보전 · 품질 검사 시스템**입니다.

- 센서 데이터 기반 설비 이상 예측 (LSTM)
- 이미지 기반 자동 불량 검출 (YOLO)
- 실시간 상태 확인을 위한 웹 기반 모니터링 대시보드

## 📌 프로젝트 개요

S.P.I.D.E.R는 공정 설비에서 수집되는 **센서 데이터(온도, 습도, 소음)**와  
제품 **이미지 데이터를 하나의 플랫폼에서 관리**하여  
설비 이상과 제품 불량을 동시에 감지하는 것을 목표로 한 프로젝트입니다.

기존 제조 현장의  
- 작업자 경험에 의존한 불량 판단  
- 사후 대응 중심의 설비 관리  
- 센서 데이터와 이미지 데이터의 분리된 관리 구조  

와 같은 한계를 개선하고자  
**AI 모델 기반 분석 + 실시간 시각화** 중심의 통합 시스템으로 설계되었습니다.

## ❗ 개발 배경 및 필요성

### 수동 판정의 한계
- 육안 검사 및 작업자 경험에 의존한 불량 판정
- 판정 결과의 일관성 부족

### 데이터 관리의 비효율
- 설비 센서 데이터와 이미지 데이터가 분리되어 관리됨
- 불량 발생 원인 분석 및 이력 추적의 어려움

### 사전 대응 시스템의 필요성
- 설비 이상 발생 이후 조치하는 구조로 인한 손실 증가
- 이상 징후를 조기에 인지할 수 있는 예측 시스템 요구

<br/>

## 💡 Solution

S.P.I.D.E.R는 **예지 보전(Predictive Maintenance)**과  
**AI Vision 기반 자동 품질 검사**를 하나의 시스템으로 통합하여  
설비 상태와 제품 품질을 동시에 관리합니다.

- 센서 시계열 데이터 → 설비 이상 예측
- 이미지 데이터 → 불량 여부 자동 판별
- 분석 결과를 웹 대시보드로 실시간 시각화

<br/>

## 🔧 주요 기능

### Predictive Maintenance (예지 보전)

- 온도 · 습도 · 소음 센서 데이터 실시간 수집
- LSTM 기반 시계열 모델을 활용한 설비 상태 예측
- 설비 상태 레벨 및 위험도 시각화

기대 효과  
- 설비 이상 조기 감지  
- 유지보수 비용 절감 및 설비 가동률 향상  

<br/>

### AI Vision (자동 품질 검사)

- 카메라 이미지 실시간 수집
- YOLO 기반 객체 탐지를 통한 외관 불량 및 라벨 이상 검출
- 불량 제품 자동 판별 및 이력 관리

기대 효과  
- 육안 검사 의존도 감소  
- 검사 품질의 일관성 확보  

<br/>

## 🧩 시스템 아키텍처 개요

- **Sensor & Camera**  
  - Raspberry Pi를 통한 센서 및 이미지 데이터 수집  

- **Communication**  
  - MQTT: 센서 데이터 송신  
  - WebSocket: 실시간 상태 전달  

- **Backend**  
  - Flask: 센서 데이터 처리 및 AI 모델 추론  
  - Spring Boot: 설비, 이력, 관리 기능 API 제공  

- **Frontend**  
  - 실시간 설비 상태 및 불량 현황 모니터링 대시보드
